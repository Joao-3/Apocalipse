# Turmas

A React + TypeScript app generated with Canvas. The page renderer, page data, interactions, and app state are in `src/App.tsx`; generated styles are in `src/App.css`.

## Run locally

```sh
npm install
npm run dev
```

Edit `src/App.tsx` to change the app and `src/App.css` to change its styles. The original visual design model is in `design.json`.
